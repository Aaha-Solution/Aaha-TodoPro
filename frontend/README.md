# India Nippon Electricals Limited - Todo Frontend

Built with React, Vite, Tailwind CSS, Redux Toolkit, and React Router.

## Features
- **Todo Landing Page** with factory building hero background, enterprise authentication, and custom branding.
- **Operational System Selection Portal** with interactive module cards.
- **Process Audit Observation** module:
  - **Creator Dashboard**: Metric KPIs and recent production requests.
  - **Create Production Request**: 5-step lifecycle target, production details, executor assignment, file attachments, and notes.
  - **Request Tracking**: Dynamic filterable table with CSV export.
  - **User Profile & Team Management**: Active profile cards and multi-role user directory with switch persona capability.
  - **Notification Center**: Real-time activity alerts and request direct actions.
  - **Line Stopper System**: Shopfloor emergency halt and quality clearance workflow.

## Running Locally
```bash
npm install
npm run dev
```
Open `http://localhost:5173`
